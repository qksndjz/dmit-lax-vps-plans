## CN2 GIA 到底是什么，为什么晚高峰才是分水岭

CN2 GIA 全称 China Telecom Next Carrier Network Global Internet Access，中国电信 AS4809 号段下的高端骨干网产品。普通 163 线路是 AS4134，中间还有一档 CN2 GT，走混合路由。

三档线路的实际差别：

| 线路 | 晚高峰延迟 | 丢包情况 | 回程是否优化 |
| --- | --- | --- | --- |
| 普通 163（AS4134） | 300ms 以上 | 可能超过 10% | 否 |
| CN2 GT | 波动明显 | 高峰期上升 | 不一定，视路由而定 |
| CN2 GIA（AS4809） | 稳定在 150–180ms | 接近 0 | 是，去回程都走 |

白天三者差距不大，因为公共互联网通道白天本来就空。真正的分水岭在工作日晚八点到十一点，普通线路被塞进拥堵节点，页面图片加载到一半卡住，用户以为是你网站的问题。

洛杉矶这条线能给的极限就是 150–180ms，电信用户第三方实测平均在 150–165ms，联通略高，移动基本同档，三网回程都走 CN2 GIA。想要 50ms 以内的国内访问体验，只能看香港机房，价格是另一个量级，不在本文范围。

## 下单前必须知道的几条限制

**流量超了不断网，只降速。** Pro 和 EB 超量后降到 4–8Mbps 继续跑（另有资料写 1–10Mbps），静态展示站基本无感，传大文件会明显变慢。比起流量见底直接停机，这个策略对站点在线率友好得多。

**25 端口默认封禁。** 想在这上面自建邮件服务器，得提前想好绕道方案，不然装完 Postfix 才发现发不出去。

**IP 被墙可以免费换，但有条件。** Pro 和 EB 系列需要同时满足：实例已购买满 7 天、距上次换 IP 满 15 天、ICMP 和所有 TCP 端口都被屏蔽、剩余服务时长不少于 7 天。其他情况换 IP 收 $5，条件是购买满 24 小时、距上次换 IP 满 24 小时。T1 系列只支持付费换 IP。IP 由系统随机分配，不能指定段或具体地址，换完不可撤销。

**热门套餐缺货是常态。** Pro.TINY 和 Pro.Pocket 尤其明显，库存页面显示有货、半小时后下单提示售罄的情况出现过。看中了当天下手。

**工单响应不快。** 非紧急问题回复可能要等 24–72 小时，建站期间对实时支持依赖度高的话要有心理准备。

**默认 SSH 密钥登录**，不是用户名密码，后台可以改成密码登录。第一次接触密钥的话，跟着官方中文教程走一遍就会。
